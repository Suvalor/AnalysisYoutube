# UI 设计文档：用户分层与订阅管理界面

> 文档类型：UI/UX 设计规范
> 日期：2026-05-19
> 状态：待评审
> 父文档：[用户分层与权限体系重构 PRD](./20260519-user-tier-permission-redesign.md)

---

## 一、设计原则

- **一致性**：复用现有 Ant Design + Tailwind CSS 组件体系，使用项目 `yc-*` 主题 Token
- **最小改动**：游客/权限限制的 UI 提示以 Overlay/Badge 形式叠加，不重构现有页面布局
- **引导优先**：权限不足时优先展示「升级引导」而非报错
- **主题适配**：所有新增 UI 支持 light / deep-blue / liblib-dark / warm-orange 四主题

---

## 二、新增页面清单

| 页面 | 路由 | 准入条件 | 优先级 |
|------|------|--------|-------|
| 管理员注册页 | `/admin-register?invite=xxx` | 有效邀请 Token | P0 |
| 订阅管理后台 | `/subscription-admin` | role=admin | P0 |
| 套餐展示页 | `/pricing` | 所有人 | P1 |

## 九、组件交互规范

### 9.1 权限不足时的通用行为

| 场景 | 用户类型 | 触发行为 | UI 呈现 |
|------|--------|--------|--------|
| 访问「蓝海雷达」 | 游客 | 前端拦截 | 全屏遮罩 + 登录引导 |
| 访问「仪表盘」 | 普通用户 | 前端拦截 | 404 或 403 提示页 |
| 调用 YouTube API（超限） | 普通用户 | 后端返回 429 | Toast 提示 + 升级 Modal |
| 调用 LLM（超限） | 付费用户 | 后端返回 429 | Toast 提示 + 详情链接 |
| 打开「模型管理」Tab | 普通用户 | 前端拦截 | 内嵌 Lock 提示 |

### 9.2 Toast 规范

```
// 配额超限
message.warning("今日 YouTube API 次数已用完（1/1），明日 00:00 重置", 4);

// 管理员邀请链接复制成功
message.success("邀请链接已复制，有效期 24 小时", 3);

// 分配订阅成功
message.success("已成功为 user@example.com 分配「基础版」订阅", 3);

// 撤销订阅成功
message.success("订阅已撤销，用户已降级为普通用户", 3);
```

## 十、主题适配要点

新增 UI 元素使用现有 CSS 变量，不新增 Token：

| 用途 | CSS 变量 |
|------|---------|
| 锁定 Overlay 背景 | `var(--color-bg-overlay)` |
| 升级按钮 | `var(--color-accent-default)` |
| 配额进度条（正常） | `var(--color-status-success-default)` |
| 配额进度条（告警） | `var(--color-status-warning-default)` |
| 配额进度条（满载） | `var(--color-status-error-default)` |
| 管理员角色 Badge | `#F59E0B`（Amber 500，四主题均可见） |
